# Участие в разработке / Contributing

Спасибо, что хотите помочь SkyKerf_Studio!

## Быстрый старт

```bash
git clone https://github.com/skysyndicatecorner/SkyKerf_Studio.git
cd SkyKerf_Studio
npm install
npm test
npm start
```

Код — обычный JavaScript без сборщика: модули в `src/js` подключаются по порядку из `src/index.html` и делят общую область видимости. Чистые подсистемы (геометрия, материалы, раскладка, траектории, постпроцессоры, миграция) покрыты тестами в `tests/`.

## Правила

- **Две локали.** Каждая строка интерфейса — `T('русский', 'English')`.
- **Без тихих подмен.** Если программа меняет параметры пользователя или не может сделать то, что просят, — она говорит об этом.
- **Честные статусы.** Не помечайте постпроцессор или материал «проверено» без реального теста; приложите отчёт.
- **Безопасность.** Ничего не загружать из сети в рантайме, не выполнять пользовательский код, не запускать станок без явного действия. Подробнее — [SECURITY.md](SECURITY.md).
- **Лицензии.** Сторонний код — только под совместимой лицензией и с записью в `THIRD_PARTY_NOTICES.md` и текстом в `licenses/`. Идеи других программ можно использовать, их код, иконки и тексты — нет.
- **Секреты.** Никаких токенов, ключей и паролей в коммитах. Для CI — только Settings → Secrets.
- **Новое старое название.** Не возвращайте «Kerf Studio» в код и документацию — тест `brand.test.js` это проверяет. Слово *kerf* как термин (ширина реза) использовать можно.

## Pull request

1. Ветка от `main`.
2. `npm test` проходит; изменения проверены в `npm start`.
3. Если меняется формат проекта — увеличьте `FORMAT_VERSION`, добавьте миграцию и тест с образцом файла в `tests/fixtures`.
4. Опишите, что изменилось, и отметьте пункты шаблона.

## Порт на macOS

Нужны: раздел `"mac"` в `package.json` (`dmg`, `zip`), иконка `build/icon.icns`, задача `macos-latest` в `.github/workflows/build.yml`; для раздачи — подпись и нотаризация Apple через секреты репозитория.

## Отчёты о станках

Самый ценный вклад — испытания на реальном оборудовании: Issues → «Проверка станка или постпроцессора».
