# Безопасность / Security

## Работа со станком

- Лазер и фрезер могут вызвать пожар, травму, повредить станок и зрение. Используйте защитные очки под длину волны лазера, вытяжку, держите огнетушитель рядом, не оставляйте станок без присмотра.
- SkyKerf_Studio **никогда не запускает обработку сама**: подключение, чтение сведений о контроллере и открытие файлов ничего не двигают. Задание стартует только кнопкой «Старт» после отметки чек-листа «Перед запуском». Тест луча, шпиндель и обвод рамки требуют подтверждения.
- Программный «Стоп» (сброс GRBL) не заменяет **аппаратную аварийную кнопку**.
- Встроенные профили материалов и постпроцессоров помечены «не проверено». Проверка кода в программе не заменяет холостой прогон.
- Лазерные профили не создаются для ПВХ, винила, поликарбоната, ABS, тефлона и стеклотекстолита.

## Программа

- Интерфейс работает без сети: страница не загружает скрипты, шрифты и G-code из интернета (Content-Security-Policy в `src/index.html`; в настольной версии сетевые запросы страницы блокируются).
- Постпроцессоры — наборы правил, а не код: подстановки и команды начала/конца проверяются по белым спискам.
- Проект не хранит пароли, сетевые ключи и другие секреты оборудования. Журнал ошибок хранится только на вашем компьютере (`logs/skykerf.log` в папке настроек) и никуда не отправляется.
- Настольная версия: `contextIsolation`, `sandbox`, без Node.js в странице; доступ только к последовательному порту, буферу обмена, полноэкранному режиму и системным шрифтам; «Показать в папке» — только для файлов, сохранённых в текущем сеансе.
- Сборки не подписаны сертификатом. Скачивайте их только со страницы Releases репозитория `skysyndicatecorner/SkyKerf-Studio`.

## Сообщить об уязвимости

Используйте **Security → Report a vulnerability** (приватное сообщение) в репозитории `skysyndicatecorner/SkyKerf-Studio`. Не публикуйте подробности в открытых задачах до исправления. Не прикладывайте пароли, токены и личные данные.
