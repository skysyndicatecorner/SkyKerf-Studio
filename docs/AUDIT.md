# Аудит Kerf Studio 0.2 (этап 0 ТЗ)

Перед доработкой версия 0.2 была проверена по коду и в браузере. Ниже — найденные дефекты, их влияние и что сделано в 0.3. Нумерация разделов ТЗ — в скобках.

## Критичные

| # | Дефект в 0.2 | Влияние | Исправление в 0.3 |
|---|---|---|---|
| 1 | Горячие клавиши сравнивали `e.key`: на русской раскладке Ctrl+Z приходит как «я», Ctrl+A как «ф» (3.1) | Отмена, выделение, копирование не работали у большинства русскоязычных пользователей | Все сочетания по `e.code` (физическая клавиша). ## Мелкие

- Подсказки параметров были только в `title` — добавлены кнопки «i» со всплывающей подсказкой и подробной справкой.
- Нет поиска команд — добавлена палитра команд (Ctrl+K) и главное меню.
- Нет оценки времени с ускорениями — добавлена; симуляция использует ту же оценку.
- В веб-версии нельзя было сохранить проект в файл — теперь скачивание `.kerf`.

## Что осталось и честно не сделано

- Импорт PDF: не поддерживается (сообщение предлагает SVG/DXF).
- Однолинейные (stroke) шрифты для гравировки одной линией не входят в поставку.
- Ни один постпроцессор и ни один материал не помечен «проверено»: на реальных станках их ещё никто не испытывал.
- Раскладка — эвристика по растровой сетке: результат допустимый, но не доказанно оптимальный.
- Определение станка работает только для GRBL-совместимых контроллеров по USB/Serial; сетевые станки и проприетарные протоколы не поддерживаются.
