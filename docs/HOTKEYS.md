# Горячие клавиши

Сочетания привязаны к **физическим клавишам**, поэтому работают на любой раскладке: на русской Ctrl+Z — это та же клавиша, что «Я». В текстовых полях Ctrl+Z, Ctrl+A, Ctrl+C и Ctrl+V относятся к тексту. На macOS вместо Ctrl — Cmd.

| Действие | Клавиши |
|---|---|
| Отменить / повторить | Ctrl+Z · Ctrl+Y или Ctrl+Shift+Z |
| Выделить всё на листе | Ctrl+A |
| Копировать / вставить | Ctrl+C · Ctrl+V |
| Дублировать | Ctrl+D |
| Сгруппировать / разгруппировать | Ctrl+G · Ctrl+Shift+G |
| Закрепить / открепить | Ctrl+L |
| Удалить | Delete · Backspace |
| Сдвиг на 1 мм / 10 мм | стрелки · Shift+стрелки |
| Повернуть на −90° / +90° | [ · ] |
| Отразить по горизонтали / вертикали | Shift+H · Shift+V |
| Переименовать | F2 |
| Снять выделение, отменить инструмент | Esc |
| Завершить ломаную | Enter |
| Раскладка | Ctrl+Shift+N |
| Новый / открыть / сохранить / сохранить как | Ctrl+N · Ctrl+O · Ctrl+S · Ctrl+Shift+S |
| Импорт файла | Ctrl+I |
| Экспорт G-code | Ctrl+E |
| Вкладки CAD / CAM / G-code / Станок | Ctrl+1 … Ctrl+4 |
| Поиск команды | Ctrl+K · Ctrl+Shift+P |
| Показать лист | F |
| Панорама | пробел + мышь, средняя или правая кнопка |
| Контекстное меню | правая кнопка без перемещения |
| Пуск/пауза симуляции (вкладка G-code) | пробел |
| Справка | F1 |

## Вкладка «Станок»

| Действие | Клавиши |
|---|---|
| Аварийная остановка | Ctrl+Пробел (и кнопка «Аварийная остановка») |
| Пауза / продолжить задание | пробел |
| Плавная остановка задания | Esc |
| Масштаб вида / весь стол | колесо мыши · двойной клик |

## Геймпад (по умолчанию, названия кнопок Xbox)

| Действие | Кнопка |
|---|---|
| Перемещение X/Y плавно | левый стик |
| Ось Z плавно | правый стик (вверх-вниз) |
| Шаг по X/Y | крестовина |
| Шаг по Z вниз / вверх | LB · RB |
| Размер шага меньше / больше | LT · RT |
| Старт всего задания / резки / гравировки | удерживать Start · X · Y |
| Пауза / продолжить | A |
| Стоп (плавный) | B |
| Аварийная остановка | Home (Xbox/PS) и всегда Back + Start вместе |
| Обвести рамку | Back |
| Ноль X/Y | L3 (нажатие левого стика) |
| Тест луча | R3 (нажатие правого стика) |

Назначение меняется в «Станок → Геймпад → ⚙» (режим обучения).

## Конструктор домов

| Действие | Клавиши |
|---|---|
| Повернуть блок | R |
| Удалить блок | Delete |
| Закончить стену/дорожку | Enter или двойной клик |
| Отменить / повторить | Ctrl+Z · Ctrl+Shift+Z |

## Инструменты (вкладка CAD)

| V | H | R | E | P | S | L | N | T | M | B |
|---|---|---|---|---|---|---|---|---|---|---|
| выбор | панорама | прямоугольник | эллипс | многоугольник* | звезда* | линия* | ломаная | текст | рулетка* | запретная зона* |

\* только в режиме «Про».
