# Форматы импорта / Import formats

SkyKerf_Studio читает только контуры (линии и кривые). Заливки, текст (не переведённый в кривые), растровые картинки и эффекты пропускаются — программа сообщает, что именно пропущено. Все размеры приводятся к миллиметрам; несколько страниц раскладываются в ряд с промежутком 20 мм.

| Формат | Расширения | Что читается | Проверено |
|---|---|---|---|
| SVG / SVGZ | `.svg`, `.svgz` | пути (все команды, в т.ч. дуги), прямоугольники со скруглением, круги, эллипсы, линии, ломаные, трансформации, единицы mm/cm/in/pt/px | да |
| DXF | `.dxf` | LINE, LWPOLYLINE (с выпуклостями), POLYLINE, CIRCLE, ARC, ELLIPSE, SPLINE; `$INSUNITS` | да |
| CorelDRAW | `.cdr` | кривые, прямоугольники (скругление, фаска, вогнутые углы), эллипсы, дуги и секторы, многоугольники и звёзды, трансформации объектов | версии 12–22 (X2–2020+): да, на 70 файлах; 6–11: **не проверено** |
| PDF | `.pdf` | контуры, `re`, формы (Form XObject), матрицы `cm`, несколько страниц, Flate/LZW/ASCII85/ASCIIHex, потоки объектов PDF 1.5 | да, на файлах из Chrome, Cairo и ReportLab |
| Adobe Illustrator | `.ai` | файлы, сохранённые с «Создать PDF-совместимый файл» — читаются как PDF | **не проверено** на реальных файлах |
| HPGL | `.plt`, `.hpgl`, `.hpg` | PU/PD/PA/PR, CI, AA/AR; 40 единиц = 1 мм | **не проверено** на реальных файлах |
| LightBurn | `.lbrn`, `.lbrn2` | прямоугольники, эллипсы, пути (линии и Безье), группы с трансформациями, резервный контур текста | **не проверено** на реальных файлах |

## Цвета, слои и режимы (0.4.0)

Вместе с контурами читается то, что задаёт смысл линий в исходной программе:

| Формат | Что сохраняется |
|---|---|
| SVG (Inkscape, Illustrator) | цвет и толщина обводки, цвет заливки, слои Inkscape (`inkscape:label`) или группы верхнего уровня, скрытые слои |
| DXF | слой (код 8), цвет ACI (62) и true color (420), цвет «по слою», выключенные и замороженные слои |
| CorelDRAW | цвет и толщина абриса (CMYK, RGB, серый, HSB, HLS), сплошная заливка; градиенты отмечаются как пропущенные. Проверено на 70 файлах версий 12–22. Плашечные цвета (Pantone и т. п.) показываются серым |
| PDF / AI | цвет обводки и заливки (RG/rg, K/k, G/g, SC/SCN), толщина линии, обводка или заливка у каждого контура |
| PLT | номер пера → цвет |
| LightBurn | слой (CutSetting): имя, тип (Cut / Scan / Image), мощность, скорость (мм/с → мм/мин), проходы, интервал, выключенный вывод |

Если в файле несколько стилей, открывается окно **«Слои из файла»**: предпросмотр, у каждого стиля — операция (резка, гравировка по линии, разметка, заливка, направляющие, не импортировать) и слой. Первое предложение: красная линия — резка, синяя — разметка, тёмная заливка — гравировка, имя слоя («рез», «грав», «cut», «engrave»…) важнее цвета, скрытые слои не импортируются, у LightBurn — тип слоя. Выбор можно запомнить для цветов. Кнопка «Всё в текущий слой» — прежнее поведение.

## G-code → рисунок

На вкладке G-code открытый или подготовленный код превращается в SVG, DXF, PNG (254 или 508 точек на дюйм; темнота = мощность лазера или глубина фрезы) или обратно в проект — контурами (через окно «Слои из файла») либо картинкой в реальном размере. Переносятся только рабочие перемещения; компенсация реза и перемычки остаются такими, как в коде.

Не поддерживается: EPS и старый AI (PostScript), CorelDRAW 1–5, зашифрованные PDF. Сохраните такие файлы как SVG, DXF или PDF.

## Как проверялся CDR

Читатель CDR написан по открытому описанию формата (проект libcdr, MPL 2.0); код libcdr не копировался. Для проверки в каждом объекте CorelDRAW хранится его габарит — программа сравнивает его с габаритом прочитанной геометрии. На 70 реальных файлах (CorelDRAW X2–2020+) совпали габариты почти всех объектов (расхождения — у 43 объектов одного файла). Примерные файлы сторонних авторов в репозиторий не включены; модульные тесты собирают маленькие CDR-файлы прямо в коде (`tests/formats.test.js`).

Если файл открылся неверно: сохраните его в CorelDRAW как SVG или DXF и сообщите о проблеме (без чужих файлов, если у вас нет прав на их распространение).

---

*English:* SkyKerf_Studio imports outlines only. Tested: SVG/SVGZ, DXF, CDR v12–22 (70 real files, object bounding boxes cross-checked), PDF (Chrome, Cairo, ReportLab output). **Not tested on real files:** CDR v6–11, AI (PDF-compatible), HPGL/PLT, LightBurn. The CDR reader was written from the public format description (libcdr, MPL 2.0); no libcdr code is included.
