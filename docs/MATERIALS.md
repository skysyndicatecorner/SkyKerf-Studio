# Материалы и калибровка

## Как устроены материалы

Материал — это профиль: название, категория, толщина, направление волокон, посадка соединений и параметры процессов.

- **Лазер:** для каждого процесса (резка, векторная гравировка, заливка, растр, разметка) — мощность, скорость, проходы, шаг строк; ширина реза (керф). Поле `ref` говорит, для какого профиля станка записаны значения.
- **Фрезер:** съём на зуб, глубина за проход (доля диаметра), обороты. Подача считается: обороты × зубья × съём.
- **Параметры под станок:** у одного материала могут быть отдельные значения для конкретного станка («Отдельные параметры для станка …»). Они важнее общих.

## Статусы

| Статус | Что значит |
|---|---|
| **не проверено** | стартовые значения; так помечены **все встроенные** профили |
| **пользовательский** | вы изменили и сохранили профиль; встроенный остаётся без изменений |
| **проверено** | профиль испытан; при выборе статуса обязательны станок, дата и условия теста |

Импортированная библиотека не может «проверить» профиль без условий теста — такой профиль получает статус «не проверено».

## Никаких тихих подмен

- Слой операции явно выбирает **«из материала»** или **«вручную»**. В CAM видно, откуда взяты значения.
- Если материал не поддерживает процесс (например, резку анодированного алюминия лазером), слой помечается предупреждением, а не получает «похожие» значения.
- Если значения записаны для другого станка или толщина листа отличается от профиля — предупреждение в CAM и в отчёте.
- Старые проекты открываются со слоями «вручную» и прежними значениями.
- Проект хранит копии использованных материалов, поэтому открывается на другом компьютере даже без вашей библиотеки.

## Опасные материалы

Названия, похожие на ПВХ, винил, поликарбонат, ABS, тефлон, стеклотекстолит, не получают лазерных профилей — ни встроенных, ни при импорте. Эти материалы при лазерной резке выделяют ядовитые и коррозионные газы. Для фрезера ПВХ доступен.

## Калибровка

1. **Тест мощности** (лазер): генератор строит матрицу «мощность × скорость». Вырежьте/выгравируйте, выберите лучшую клетку, введите значения в материал.
2. **Тест керфа**: полоски заданной ширины в рамке. Сожмите полоски вместе, измерьте суммарную длину штангенциркулем; генератор подскажет формулу. Введите результат в поле «Ширина реза».
3. **Тест соединения**: пазы с разным зазором (от тугого к свободному). Вставьте пробную деталь, выберите подходящий паз и введите зазор в «Посадка соединений».
4. В CAM нажмите **«Сохранить значения в материал…»** — значения слоя запишутся в материал для текущего станка, статус станет «пользовательский».

## Обмен библиотеками

**Материалы → Экспорт моих / Импорт…** — файл `skykerf-materials.json`. Импорт заменяет профили с тем же `id`, встроенные профили не меняет.
